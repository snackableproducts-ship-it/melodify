# Melodify

A client-side Fabric mod for Minecraft Java 1.21.11 that displays synchronized lyrics for the song currently playing on Spotify.

## Project status

This repository has been created, but the source files from the original `melodify.zip` have not yet been uploaded. The mod has not been built or verified from this repository.

## Requirements

- Minecraft Java 1.21.11
- Fabric Loader and Fabric API
- Java 21
- Spotify Developer app credentials

## Source project

The original source archive was provided in the ChatGPT conversation. It contains the Gradle project, Fabric metadata, Spotify integration, lyrics service, HUD, and in-game settings screens.
