# Melodify

A client-side Fabric mod for Minecraft Java 1.21.11 that displays synchronized lyrics for the song currently playing on Spotify.

## Source

The complete original project is included in [`melodify-source.zip`](./melodify-source.zip). Download it from this repository and extract it to build or modify the mod.

## Build

The GitHub Actions workflow automatically extracts the source archive and runs the Gradle build with Java 21. Download the resulting `melodify-jar` artifact from the Actions run.

## Requirements

- Minecraft Java 1.21.11
- Fabric Loader and Fabric API
- Java 21
- Spotify Developer app credentials (see the full source README for setup)

## Notes

This repository contains the project source supplied by the user. The mod has not yet been independently build-verified.
